# Nandita G N: Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript (no frameworks).

## Sections
Hero, About, Skills, Projects (with a filter), Contact.

## Features
- Semantic HTML (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Responsive at 375px, 768px and 1280px+
- JavaScript: dark/light theme toggle, mobile nav toggle, project filter, smooth scroll
- Keyboard accessible, with a skip link and visible focus styles

## Tech used
HTML5, CSS3 (custom properties, grid, flexbox), vanilla JavaScript. Fonts: Bricolage Grotesque and IBM Plex Sans via Google Fonts.

## Run locally
1. Clone the repo: `git clone <your-repo-url>`
2. Open the folder in VS Code and start the **Live Server** extension, or just open `index.html` in a browser.

## Files
- `index.html`: page structure and content
- `style.css`: styles and themes
- `script.js`: interactions
